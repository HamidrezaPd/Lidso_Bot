# ربات فروش Lidso (VPN Shop Bot)

## ✅ این پروژه چیه؟
یک ربات تلگرامی کامل برای فروش سرویس وی‌پی‌ان با:
- منوی خرید (دسته‌بندی‌های دلخواه، هرکدوم با چند مدت‌زمان/حجم/قیمت)
- کیف پول با سه روش پرداخت (کارت‌به‌کارت با تایید دستی ادمین، درگاه HooshPay خودکار، پرداخت ارزی TON/USDC خودکار) - هرکدوم جدا از بات ادمین قابل فعال/غیرفعال کردنه
- حداقل/حداکثر مبلغ شارژ جدا برای هر روش پرداخت
- تست رایگان (هر کاربر یک‌بار، با پنل/حجم/مدت‌زمان دلخواه، حذف خودکار فوری بعد از اتمام حجم یا زمان)
- انبار کانفیگ (اول انبار چک میشه، اگه خالی بود از پنل می‌سازه)
- اتصال چندپنلی (Marzban / PasarGuard / YouPanel) - هرکدوم پیاده‌سازی کاملاً مستقل خودشون
- ادغام ساب اختصاصی (PhantomHubs) - قابل فعال/غیرفعال جدا برای هر پنل
- تمدید اشتراک + حذف خودکار بعد از ۷۲ ساعت عدم تمدید (هم از پنل هم از ادغام ساب)
- کد تخفیف (مصرف واقعی فقط موقع خرید ثبت میشه، نه موقع وارد کردن کد)، رفرال، پروفایل کاربر
- رنگ‌بندی و ایموجی پرمیوم برای دکمه‌های منو، دسته‌بندی‌ها و پلن‌ها
- پنل مدیریت کامل داخل همین ربات با دستور `/admin` (فقط برای آیدی‌های داخل `ADMIN_IDS`) - تقریباً هرچیزی که توی ربات هست از همینجا قابل ویرایشه

## 🚀 اجرا روی سیستم خودت

### ۱. پیش‌نیازها
- Python 3.10 یا بالاتر نصب باشه (`python3 --version`)

### ۲. نصب پکیج‌ها
```bash
python3 -m venv venv
source venv/bin/activate        # ویندوز: venv\Scripts\activate
pip install -r requirements.txt
```

### ۳. تنظیم فایل .env
یک فایل `.env` توی ریشه پروژه بساز و مقادیر زیر رو پر کن:
- `BOT_TOKEN` → از [@BotFather](https://t.me/BotFather)
- `ADMIN_IDS` → آیدی عددی خودت (از [@userinfobot](https://t.me/userinfobot) بگیر)، چند تا رو با کاما جدا کن
- `BOT_USERNAME` → یوزرنیم ربات بدون @ (برای لینک رفرال)
- `DATABASE_URL` → پیش‌فرض `sqlite+aiosqlite:///lidso_database.db` کافیه. برای PostgreSQL به `POSTGRESQL_MIGRATION.md` نگاه کن.

### ۴. پروکسی (فقط برای اجرای محلی داخل ایران - روی سرور خارج لازم نیست)
اگه سیستمی که ربات روش اجرا میشه به تلگرام دسترسی مستقیم نداره، توی `.env`:
```
PROXY_URL=socks5://127.0.0.1:10808
```
روی سرور خارج (بدون فیلترینگ) این مقدار رو خالی بذار.

### ۵. اجرا
```bash
python3 main.py
```
پایگاه داده خودکار ساخته میشه و migration های لازم (ستون‌های جدید و غیره) خودکار روی هر اجرا اعمال میشن.

## 🔧 چیزهایی که باید خودت تنظیم کنی (از `/admin`)

### الف) پنل وی‌پی‌ان
«🖥 پنل‌ها» → «➕ افزودن پنل جدید»: اسم، نوع پنل (`marzban`/`pasarguard`/`youpanel`)، آدرس، یوزرنیم/پسورد ادمین پنل.

⚠️ برای Marzban حساب پنل باید **sudo/admin کامل** باشه، وگرنه با خطای 403 روی username هایی که خودش نساخته مواجه میشه.

بعد از ساخت پنل، از صفحه‌ی همون پنل می‌تونی:
- (فقط PasarGuard) Group IDs رو تنظیم کنی
- (فقط Marzban) پروتکل و تگ اینباند رو تنظیم کنی (خالی = خودکار از پنل گرفته میشه)
- ادغام ساب اختصاصی همون پنل رو فعال/غیرفعال کنی

بعدش از «🔗 اتصال یک سرویس به پنل» هر پلن رو به همون پنل وصل کن.

### ب) متن‌ها، دکمه‌ها، رنگ‌ها
«⚙️ تنظیمات» شامل:
- ویرایش متن تعرفه‌ها/آموزش/خوش‌آمدگویی (با پشتیبانی فرمت و ایموجی پرمیوم)
- ویرایش هر دکمه‌ی منوی اصلی (متن + رنگ + ایموجی پرمیوم) از دو مسیر: «🎛 ویرایشگر منو» یا «✏️ ویرایش متن‌ها»
- روشن/خاموش کردن هر روش پرداخت
- حداقل/حداکثر مبلغ شارژ برای هر روش
- اجبار شماره تلفن برای کارت به کارت

### ج) تست رایگان
«🎁 تست رایگان» توی منوی ادمین: افزودن هر تعداد سرویس تست (نام، حجم به مگابایت، مدت‌زمان، پنل)، فعال/غیرفعال کردن هرکدوم، و دکمه‌ی ریست برای همه‌ی کاربرا.

### د) انبار کانفیگ (اختیاری)
«📦 انبار کانفیگ» → «➕ افزودن به [پلن]». ربات همیشه اول انبار رو چک می‌کنه، اگه خالی بود میره سراغ ساخت خودکار از پنل.

### ه) درگاه پرداخت و کریپتو
- درگاه: تنظیمات HooshPay از «💳 تنظیمات درگاه»
- کریپتو: آدرس ولت TON/BSC از «🪙 تنظیمات کریپتو»

### و) ادغام ساب (PhantomHubs)
«🔗 ادغام ساب» برای تنظیمات کلی + توکن. یادت نره بعدش برای هر پنل جدا هم فعالش کنی (از صفحه‌ی همون پنل).

## 📂 ساختار پروژه

```
Lidso_Bot/
├── main.py                        # نقطه ورود، اجرای ربات
├── config.py                      # تنظیمات از .env
├── database.py                    # مدل‌های دیتابیس (SQLAlchemy async) + migration خودکار
├── seed_data.py                   # پر کردن پلن‌ها/متن‌های پیش‌فرض
├── ui_texts.py                    # سیستم متن‌ها/رنگ/ایموجی دکمه‌ها
├── panels.py                      # اتصال چندپنلی (Marzban/PasarGuard/YouPanel)
├── submerge.py                    # ادغام ساب (PhantomHubs)
├── crypto.py / rates.py / hooshpay.py   # پرداخت ارزی و درگاه
├── scheduler.py                   # یادآوری تمدید، حذف خودکار، چک تست‌های منقضی
├── middleware.py                  # عضویت اجباری کانال
├── migrate_sqlite_to_postgres.py  # مهاجرت یک‌باره‌ی دیتابیس
├── handlers/
│   ├── user.py                    # پروفایل، رفرال، سرویس‌های من، تمدید، شروع
│   ├── shop.py                    # فرایند خرید سرویس
│   ├── wallet.py                  # کیف پول (کارت/درگاه/ارزی/کد تخفیف)
│   ├── trial.py                   # تست رایگان
│   └── admin.py                   # پنل مدیریت کامل (/admin)
├── keyboards/
│   ├── user_kb.py
│   └── admin_kb.py
└── states/
    ├── admin_states.py
    └── user_states.py
```

## ⚠️ نکات امنیتی مهم
- فایل `.env` توی `.gitignore` هست، هیچ‌وقت به گیت‌هاب پابلیک پوش نکن.
- وقتی پسورد پنل رو توی چت ربات ادمین می‌فرستی، ربات خودش پیام رو حذف می‌کنه.
- توکن‌های ادغام ساب و پنل‌ها فقط داخل دیتابیس ذخیره میشن، هیچ‌وقت به کاربر عادی نمایش داده نمیشن.

## 🚀 بردن روی سرور
برای مهاجرت به PostgreSQL و آپلود به سرور، `POSTGRESQL_MIGRATION.md` رو ببین.
برای اجرای دائمی روی Ubuntu با systemd (تا با ریبوت سرور یا crash خودکار بالا بیاد)، `DEPLOY_UBUNTU.md` رو ببین.
یه فایل `.env.example` هم توی ریشه‌ی پروژه هست که می‌تونی ازش کپی کنی و پر کنی.
